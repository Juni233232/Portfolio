    Unit 1 · Fitts's law

    Touch target sizer

    Bigger, nearer targets are easier to hit. Apple suggests about 44 pt, Material Design 48 dp.

    Register

    Verdict

    One CSS pixel is close to one point on a phone. Treat the guideline as a minimum, and add space between targets.

    Unit 1 · Hick's law

    More choices, more thinking

    Decision time grows with the number of options. Drag to add menu items to Gather's navigation.

    Relative effort, log₂(n + 1)

    A simple model, not a stopwatch. Real timing depends on familiarity, grouping and layout.

    How it is designed

    An Apple-inspired system. Checked, not assumed.

    The deck and this site share one set of tokens: one accent, flat surfaces, hairlines, three font weights, and a type ramp. The numbers below are computed live.

    Design tokens

    One accent, flat surfaces

    • One accent blue. Lavender only as a soft surface.
    • Pill buttons and hairline borders, no chrome shadows.
    • A soft shadow only under the product mockup.
    • Weights 400, 600 and 700 only.

    Fluid motion

    Feels instant, stays interruptible

    • Press feedback starts on touch, before release.
    • Phone screens and the slide viewer use springy, cancellable transitions.
    • Reduced motion switches movement off.
    • Every page is complete before any animation runs.

    HIG review

    Accessible by default

    • Contrast of 4.5:1 for small text, 3:1 for large text.
    • Touch targets of at least 44 px.
    • Meaning is never carried by colour alone.
    • Sentence case, visible labels, clear focus rings.
